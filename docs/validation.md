# 验证记录与复测

以下为项目已完成验证的汇总，已移除实际域名、邮箱、账户和部署版本等信息。原始报告、截图及具体部署记录应保存于 Git 忽略的 `test-results/` 或 `.private/`。

## 自动检查

运行 `npm run check`：

- 前端、Worker 和测试 TypeScript 类型检查。
- 63 项 Workers Vitest 集成测试，涵盖认证开关、Google 白名单和令牌校验、回调重放、持久化锁定、上传完整性、并发名额、流式传输、租约续期、额度、删除失败和重启恢复。
- Vite 生产构建及 Wrangler dry run。

故意截断或超长的上传流会令本地 R2 模拟器输出连接中断诊断；相关用例会确认错误分片被拒绝，并验证后续重试。

## 复测方式

密码或免认证模式下，在独立测试部署运行 `npm run test:large` 和 `npm run test:browser`。通过 `LITE_DROP_URL` 指定目标，密码模式另设 `LITE_DROP_PASSWORD`。大文件验证会使用 R2 存储及读写额度；浏览器测试会触发当前 IP 的锁定。

Google 模式下：

```powershell
$env:LITE_DROP_URL = "https://drop.example.com"
node scripts/google-ui-smoke.mjs
```

将示例地址替换为自己的测试部署。该脚本检查页面、隐私页及未登录拦截，不访问 Google 账号，也不上传文件。完整登录需在浏览器选择自己的白名单账号；不要把实际账号、授权码或会话 Cookie 写入公开测试报告。
